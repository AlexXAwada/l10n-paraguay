EDI Batch Sending (SIFEN)
---------------------------

This module provides batch sending and queue management for EDI documents in
Paraguay via SIFEN.

**Features:**

* Batch sending of up to 50 documents per call (pysifen limit)
* Queue management with progress tracking
* Status check batch processing
* Cancel batch processing
* Retry failed lines
* Cron job for automatic processing
* Wizard for easy batch creation from invoice list

**Usage:**

1. Install the module
2. Go to *Paraguay EDI > Batch Jobs*
3. Click *Create* to create a new batch job
4. Select invoices, batch type (send/status_check/cancel), and batch size
5. Click *Create and Run* to start processing

**Batch Types:**

* **Send Documents**: Send multiple invoices to SIFEN in batch
* **Check Status**: Query status of multiple documents in batch
* **Cancel Documents**: Cancel multiple documents in batch

**Requirements:**

* l10n_py_edi_base
* l10n_py_edi_sifen
