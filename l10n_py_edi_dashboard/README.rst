This module provides an **EDI Dashboard** for Paraguay localization,
displaying key performance indicators and operational statistics
for electronic document management via SIFEN.

Features
========

* **KPI Cards**: Total documents, pending, accepted today, rejected today
* **Document Type Breakdown**: FE, AFE, NCE, NDE, NRE counts
* **Batch Operations Stats**: Active batches and success rate
* **Contingency Mode Tracking**: Documents pending sync
* **Quick Actions**: Navigate to pending, rejected, or contingency documents

Usage
=====

Install the module and access the dashboard via:

*Menu*: ``Invoicing / Paraguay EDI / EDI Dashboard``
