**This module is part of the OCA/l10n-paraguay project.**

The EDI Reject Resolution module provides tools to handle rejected EDI documents from SIFEN.

When a document is rejected by SIFEN, users can:

* View the rejection error with actionable messages
* Identify which field caused the rejection
* Correct the field directly through a wizard
* Automatically recalculate CDC and resubmit

Features
========

* Single document rejection resolution wizard
* Batch retry for multiple rejected documents
* Rejection history tracking
* Automatic CDC recalculation after fixes
* Integration with SIFEN error code interpreter

Usage
=====

Single Document Resolution
-------------------------

1. Go to the rejected invoice
2. Click "Resolve Rejection" button
3. Select the field to correct
4. Enter the new value
5. Click "Apply Fix and Retry"

Batch Retry
-----------

1. Go to EDI > Batch Retry Rejected
2. Select multiple rejected documents
3. Choose fix type (RUC, Taxpayer Type, or none)
4. Apply and retry all
